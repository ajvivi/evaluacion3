Consejos y privacidad

El esmalte se coloca de forma aproximada usando las articulaciones de los dedos. No detecta el contorno real de las uñas ni distingue siempre la palma del dorso. Usa una sola mano extendida; ajusta cada uña u oculta el dedo si se alinea mal. Para mayor control puedes usar Uñas con foto.

Procesamiento local en el navegador, sin grabaciones ni envío de imágenes. Se necesita internet para descargar el detector. El recorte muestra la zona de las manos; no elimina otros objetos que estén dentro de esa zona.
